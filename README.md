# 実感家計簿

一日にいくら使ったかを手入力で記録して、支出を「実感」するためのスマホ向け家計簿アプリ（PWA）。
データはすべて端末内（ブラウザの IndexedDB）に保存され、サーバーには送信されません。

**公開ページ**: https://htoma19.github.io/kakeibo/

## 主な機能

- **ホーム** — 今日の支出合計、1日の目安額までの残り、今週・今月の合計、目安以内の連続日数、時給換算（労働◯時間分）
- **入力** — 右下の＋からキーパッドで素早く入力。よく使う支出のワンタップ候補（履歴から自動学習）、メモ・日付の指定
- **振り返り** — 今週/今月の日別グラフとカレンダー、カテゴリ別内訳、先週・先月との比較、年間ペース試算
- **レポート** — 月次・年次の集計（目安 − 支出 ＝ 残り）、カテゴリ別内訳とタップでの明細表示
- **履歴** — メモ・カテゴリ・期間・金額での検索
- **設定** — 1日の目安額、時給、カテゴリの追加・編集・並べ替え、バックアップの書き出しと復元

## 技術構成

- React 18 + Vite
- IndexedDB（`idb-keyval`）にローカル保存
- Chart.js（`react-chartjs-2`）でグラフ表示
- `vite-plugin-pwa` でホーム画面追加 / オフライン対応

## フォルダ構成（src/）

| ファイル | 役割 |
| --- | --- |
| `App.jsx` | 全体の状態管理・タブ切り替え・保存処理 |
| `db.js` | IndexedDB への保存と読み込み、初期データ |
| `backup.js` | バックアップの書き出し、復元データの検証、リマインダー判定 |
| `utils.js` | 日付・金額・集計などの共通関数 |
| `chart.js` | グラフ（Chart.js）の共通設定 |
| `components/` | 各画面（Home, Review, MonthlyReport, HistorySearch, Settings）と部品（AddExpenseSheet, Sheet, ExpenseList など） |

## 開発の始め方

```bash
npm install      # 初回のみ
npm run dev      # 開発サーバー起動（http://localhost:5173）
```

iPhone の実機で試すには、PC と iPhone を同じ Wi-Fi につなぎ、
`npm run dev -- --host` で表示される `http://192.168.x.x:5173` を Safari で開きます。

```bash
npm run build    # dist/ に本番ファイルを出力
npm run preview  # ビルド結果をローカル確認
```

## 公開（デプロイ）

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）が
自動でビルドして GitHub Pages に公開します（約1分）。手動での作業は不要です。

リポジトリ名を変えた場合は、`vite.config.js` の `REPO_BASE` を `'/新しい名前/'` に変更してください。

## データとプライバシー

- 保存先は端末内（ブラウザの IndexedDB）。クラウド同期はなく、1台で完結します。
- iOS はブラウザの保存領域を消すことがあるため、**設定画面から定期的にバックアップ（JSON）を書き出し**、
  「ファイル」アプリや iCloud に保存しておくと安心です（アプリ内でも定期的にお知らせが出ます）。
- 「ホーム画面に追加」すると保存領域が消えにくくなります。
- バックアップ JSON には支出の記録がそのまま入っています。人に渡したり公開の場所に置いたりしないよう注意してください。
- 復元時はファイルの中身を検証し、想定している項目だけを取り込みます。
